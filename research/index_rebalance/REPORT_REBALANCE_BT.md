## 四、任务 C：面板回测骨架（合成数据验证）

### 4.1 正向：管道跑通（**合成数据，非结论**）

```bash
python backtest/make_synth_kline.py --out /tmp/synth
python backtest/run_panel_backtest.py \
  --data-dir /tmp/synth \
  --events out/events.parquet --members out/members.parquet \
  --out out/synth
```

结果：产出 **13,872 条观测**、32 组「指数×方向×窗口」汇总，
`panel_summary.csv` / `cost_sensitivity.csv` / `panel_detail.csv` 三张表均非空。
成本三档差额精确等于 5bp（8→13→18），算术自洽。

> ⚠️ **合成数据的 in/out 均值在部分窗口相同** —— 原因是 **703 例「同一公告日、
> 同一股票在某指数调入、在另一指数调出」**（如沪深300 调入 = 中证500 调出），
> 我构造的 ±漂移恰好抵消。这是**合成数据的性质，不是管道 bug**：
> 已验证每个 `(notice_id, index)` 的 in/out 股票集合**严格互斥**。

### 4.2 反向：缺分区时清晰失败

| 场景 | 退出码 | 输出 |
| --- | --- | --- |
| `--data-dir` 指向不存在目录 | **2** | `❌ ...\kline_daily 下没有 date= 分区` |
| 日 K 最早 2022-01-03（晚于所需 2021-04-18） | **3** | `❌ 最早分区 2022-01-03 晚于所需起点 2021-04-18` + `缺口约 260 天 —— 需先补齐日 K 再跑` |

**fail-closed**：缺数据直接停，不静默出空表、不降级成假结论。

### 4.3 回测口径（写死）

| 项 | 口径 |
| --- | --- |
| 收益 | 个股**前复权收盘价**简单收益 |
| 基准 | **同指数**（`kline_index_daily`），缺失不替换 |
| 窗口 | `T0-5..T0+5`、`T0..T0+10`、`E-5..E+5`、`E..E+10`；另 `BH_T0_E`（公告收盘买→生效收盘卖） |
| 成本 | 单边 8/13/18 bp，**主结论 13 bp**；`BH_T0_E` 往返 2× |
| 汇总 | 分组均值 + t，含**按公告日聚类**的稳健 t（cluster < 5 回退普通 t） |

## 五、已知限制（读结论前必看）

| 限制 | 说明 |
| --- | --- |
| **时间范围** | 完整名单自 **2021-05** 起。2018–2020 官网只有新闻稿摘要，无完整名单（源缺口，非抓取问题）。样本为 **11 次调整 / 32 个指数×事件**。 |
| **升降级重复计数** | 703 例「同一股票在某指数调入、另一指数调出」是同一次调整的两种角色。做面板回归时若同时纳入 in 与 out，需在模型里处理这种配对，**不能当独立样本**。 |
| **公告时点** | 公告通常在**收盘后**发布，`T0` 锚点用公告日当天收盘价，理论上含极小前视。更严格口径要把锚点后移 1 个交易日（属稳健性检查，非放宽门槛）。 |
| **2018–2019 不补** | 按任务书要求不为凑样本掏付费库。 |
