## 1. 产品语义

独立只读影子观测口（**R2-3**）。供研究/观测侧只读查看「影子轨迹」—— 在**不影响生产**的前提下，看一条信号按未锁定口径会怎么走。

四条写死：

1. **独立**：不并入 live 存储、不并入生产外发、不并入 `/hits/scope` 载荷正文
2. **只读**：观测口**只读**，没有任何写路径。写影子是 P3b 的事（`write_shadow_hits`），观测口不写
3. **默认关闭，显式打开**
4. **带空态/过期标记**：状态必须能说出「为什么看不到」，而不是安静地返回空列表

### 1.1 为什么「独立」是硬要求而不是洁癖

影子命中与生产命中**形状完全一致**（P3a `REASON_SHADOW` 的 docstring 已经写过这一点）。形状一致意味着：一旦观测口的内容能流进任何生产通路，它就没有任何形态特征可供下游区分——下游会把它当生产命中处理。

所以隔离**不能靠约定**，只能靠「压根不给通路」：观测口只读、只出、不入库、不外发。

## 2. 默认关 / 显式开

锁面常量：`SHADOW_OBS_DEFAULT_ENABLED = False`。

| 项 | 规定 |
|---|---|
| 默认值 | `False`（**写死**） |
| 开启方式 | **显式**。不存在「配了 URL 就自动开」「有影子数据就自动开」这类隐式开启 |
| 本拍范围 | **只钉常量与契约**。生产开关注入、环境变量、开关路由 —— **全部另口令** |
| 关闭时读 | 返回 `closed` 标记，**不返回空列表冒充「没数据」** |

**为什么默认关而不是默认开**：默认开 + 出了问题是「忘了关」；默认关 + 出了问题是「明确开过」。后者的责任链可追。这与两处 `*_TRIGGERING_ENABLED = False` 同一个取向。

## 3. 空态 / 过期标记

枚举 `SHADOW_OBS_STATE_MARKERS = {closed, empty, stale, ok}`。

| 标记 | 语义 | 零条目？ | 可读内容？ |
|---|---|---|---|
| `closed` | 观测口**未开启**（默认态或显式关闭） | 是 | 否 |
| `empty` | **已开启**，但分桶内无任何影子条目 | **是** | 否（确实没有） |
| `stale` | 有内容，但**已过期**（超出新鲜窗口） | 否 | 是，但须标注不可当真 |
| `ok` | 有内容，且**未过期** | 否 | 是（**≠ 可放量**） |

### 3.1 状态转移

```
closed ──[显式开启]──> empty ──[P3b 写入影子]──> ok
                          ^                      │
                          │                      │[超出新鲜窗口]
                          └──[条目被清空]────────┴──> stale
```

`stale` 与 `ok` 之间可双向（新条目写入 → `ok`；时间推移 → `stale`）。

### 3.2 空桶**不得**报 `ok` 或 `stale`（本契约的关键约束）

一句话：**空桶不得报 `ok`**、也不得报 `stale`。

**零条目只能报 `empty`。** 不允许出现：

- 空桶 → `ok`（"看起来一切正常"，实际没有任何数据）
- 空桶 → `stale`（没东西谈不上过期）

**理由**：允许空桶报 `ok`，观测口就永远显示健康、永远不暴露「根本没数据」这个事实。这与 T1「**无量＝无档**、禁止拿 `weak` 顶缺失」是**同一个错误**的两种形态——**拿一个"看起来正常"的值去顶"什么都没有"**。

`empty` 是一个**诚实的坏消息**；`ok` 是一个**不诚实的假好消息**。宁可让观测口报 `empty`。

> 本条由测例负控钉死：注入「空桶返回 ok」，测例必须炸。

### 3.3 `stale` 的判定阈值不在本拍

新鲜窗口的具体秒数、时钟来源、时区 —— **本拍不实现**（观测口不算行情、不读时钟）。本拍只钉「存在 `stale` 这个标记、且它必须与 `ok` 可区分」。

阈值落地属**另口令**（观测 UI 接线时一并定）。

## 4. 不并入 `/hits/scope`

观测内容**默认不**进入 `/hits/scope` 载荷。

| scope 载荷允许含 | scope 载荷**禁止**含 |
|---|---|
| P3a 已合的 `non_live_mode_rejected` 报警**计数** | 影子明细（条目、桶内容、逐条字段） |
| 各闸的**聚合计数** | 影子条目的 `signal_id` / 档 / 方向 / 任何逐条字段 |

### 4.1 `non_live_mode_rejected` 是报警，不是统计

它的**常态是 0**。非 0 意味着：**有影子命中漏进了生产可见层** —— 那是 P3a 闸被绕过的信号，不是「影子用得挺多」的进度条。

所以它进 scope 是**告警**语义，不是把影子内容搬进 scope 的许可。两者不可混：**计数可以进，明细不可以进**。

### 4.2 为什么明细不能进 scope

`/hits/scope` 是生产监控口，会被生产侧的巡检、看板、告警规则消费。影子明细一旦进去：

1. 生产看板会开始展示未锁定的内容——观众无从分辨
2. 影子条目形状与生产一致（见 §1.1），消费方无法靠形状区分
3. 一旦有人基于 scope 做自动化决策，影子内容就成了事实上的生产输入

锁面为此提供 `SHADOW_OBS_SCOPE_MUST_NOT_CONTAIN`（禁止键名集）供测例断言。

## 5. 只读 P3b 三键分桶

按 **`signal_id` + `definition_version` + `freq_lock_version`** 三键定位独立分桶。

| 项 | 规定 |
|---|---|
| 三键 | 由 P3b `SHADOW_BUCKET_KEYS` **派生**（不抄字面量，见 §11.1） |
| 读 | **只读** P3b 分桶 |
| 写 | **不写**。写影子的唯一入口是 P3b `write_shadow_hits` |
| 扩 live | **不扩**。不新增 live store、不改 live `hits.json` 写入路径 |
| 复用 | P3b `list_shadow_hits` 可作**测钩**复用 |

### 5.1 `list_shadow_hits` ＝ 核验钩子 ≠ 观测口

P3b 的 `list_shadow_hits` docstring 明文写着「这是核验钩子, 不是 R2-3 观测口」。差别是实打实的：

| 维度 | `list_shadow_hits`（P3b 核验钩子） | R2-3 观测口（本契约） |
|---|---|---|
| 用途 | 测试与人工核验 | 研究/观测侧只读查看 |
| 分页 | 无 | 契约要求（实现另口令） |
| 过期标记 | 无 | **有**（§3） |
| 权限 | 无 | 契约要求（实现另口令） |
| 状态语义 | 无（空就是空列表） | **有**（`closed`/`empty`/`stale`/`ok`） |
| 默认关 | 无此概念（函数随时可调） | **有** |

**核验钩子能用 ≠ 观测口已开通。** 本拍不提供观测口实现，只锁契约。

## 6. 兼容 T1 / T2

观测侧展示载荷遵循 **T1/T2 四元组**：

```
track + asof_grain + mode + (tier 或 显式无档)
```

| 项 | 规定 | 来源 |
|---|---|---|
| 必填四元组 | 前三项由 T1 派生；`tier` 由 T2 派生 | 只读 import |
| `mode` 值域 | `{shadow, observation, live}` | T1 `TIER_DISPLAY_MODES` |
| 影子内容的 `mode` | **`shadow`**（写死字面量） | P3b `SHADOW_MODE` |
| 方向 | `{research_buy, research_sell, research_watch}` | `DIRECTION_LABELS`，**零碰** |
| 档 | `{weak, mid, strong}` 或**显式无档** | T1 `TIER_LABELS` / T2 `no_tier` |
| 措辞 | **禁六词动作指令式**；短动作词只查档名 | T2 §4.2 |
| 字段 | **禁价量仓单**（`price/quantity/position/order` + 中文） | T2 |

### 6.1 `shadow` 与 `observation` 不是同义词

- `shadow` ＝ **内容的来源模式**：这条命中是影子命中（P3b 分桶里存的就是这个）
- `observation` ＝ **读取态标记**：观测口正被以观测方式读取

一个观测口里读到的条目，其 `mode` 是 `shadow`（内容的属性）；观测这个动作本身属 `observation`（读者侧属性）。**两者不可互换**，混用会让「这条内容是哪来的」这个问题失去答案。

**只读交叉，不重写 T1/T2。** 本契约不重定义任何阈值、measure id、四元组语义或 version。
