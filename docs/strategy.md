# 策略指南

策略是选股引擎、回测、监控的基础。本文介绍策略体系与三种扩展方式。

完整策略开发规范(AI 生成与手写)见 [`backend/app/strategy/prompts/strategy-guide.md`](../backend/app/strategy/prompts/strategy-guide.md)。

## 内置策略

**28 个内置策略**,每个策略一个独立 Python 文件(`backend/app/strategy/builtin/`)。价格形态用 Polars 表达式或矩阵后端；下面三套基本面预设按公告日读财务报表。

| 类型        | 代表策略                                                 |
| :---------- | :------------------------------------------------------- |
| 趋势 / 形态 | 趋势突破 · 均线多头 · MA 金叉 · MACD 金叉放量 · 布林突破 · 均线粘合突破 · 平台整理突破 · 放量创60日新高 |
| 量价 / 涨停 | 量价齐升 · 高换手强势 · 连板股 · 断板反包 · 涨停动量 · 接近涨停 · 涨停基因活跃股 |
| 反转 / 波动 | 超跌反弹 · 超卖反转 · 新低反转 · 低波动龙头 · 回踩 MA20 · 回踩支撑 · 强势开盘 · MACD 零下回升 · 长下影反击 · RSI 中轴回踩 |

内置目录 `backend/app/strategy/builtin/` 还包含一个仅供挖掘 worker 使用的受控因子排名研究模板。它不出现在普通选股列表，也不能通过普通策略 API 直接运行或保存 override；挖掘结果发布时会生成独立策略。详见 [因子与策略挖掘](./mining.md)。

内置目录 `backend/app/strategy/builtin/` 由项目维护,**AI 生成的策略不会落入此目录**。

### 基本面预设

选股页策略列表里有三套基本面预设，说明文字来自策略描述。展示名只写在 `backend/app/strategy/fundamental_screens.py` 的 `SCREEN_NAMES`，策略 id 保持 `fundamental_m1` / `m2` / `m3`。名字以后若调整，改这一处即可。财务数字只在公告日的次日生效（公告多在盘后，当天不用）。同一报告期若有更正，用当时已经公告的那一版。ROE、净利率、资产负债率和同比增速按百分数数值比较（`12` 表示 12%）。增速分母、权益或总资产缺失时不通过。商誉、短期借款、长期借款在 `data/financials` 里没有这一行时存的是 null，不是 0：TickFlow 把可选字段留空，扶摇只写入有数字的扩展列。成长质量精选把 null 商誉当成 0 再除以总资产；长期价值白马把 null 的短期和长期借款当成 0 再算 ROIC。M3 的 ROIC 仍要求借款字段本身有值。

| 预设 | 条件 |
| :--- | :--- |
| 成长质量精选（M1） | 扣非净利同比在 0 到 400% 之间，且增速环比变化率 `(g_t-g_{t-1})/\|g_{t-1}\|` 大于 -10%；营收同比为正，增速环比变化率同样大于 -10%；同花顺二级行业里 ROE 百分位不低于 0.70；单季毛利率比上一季少降不超过 1 个百分点；资产负债率低于 70%；商誉/总资产低于 25%；最新报告经营现金流为正；PE(TTM) 大于 0 且小于 80。通过后按 ROE（高优先）、扣非增速（高优先）、PE（低优先）三项平均名次排序，每个交易日默认取前 30 只，数量可改。扣非增速缺失或 PE 小于等于 0 的不参与排序 |
| 长期价值白马（M2） | 近三年年报平均 ROE / PB 大于 2.5%；最近三份季报净利率都大于 10%，这三期净利增速的平均值大于 20%；三年平均 ROE 大于 10%；最新年报 ROIC 大于 WACC（默认 8%，界面可改；大于 1 时按百分数理解）；连续五个会计年度经营现金流为正；最新年报净利增速高于上一份年报；同花顺一级行业不是银行或非银金融。保留全部通过的股票，不按数量截断。行业文件缺失或没有「所属同花顺行业」列时接口返回错误，不会给空名单 |
| 稳健现金流（M3） | 资产负债率低于 55%；经营现金流/营收大于 5%；营收同比为正；最近三个会计年度的 ROIC 都高于同花顺二级行业当年中位数；最近三年经营现金流都为正，并且用四年现金流看同比增加，三年里至少两年增加；PE(TTM) 大于 0 且小于 80。通过后按总市值从高到低，每个交易日默认取前 30 只，数量可改 |

扣非同比没有单独的指标列，用利润表扣非净利润的累计值对上年同期计算。营收同比、净利同比优先用指标表里的 `revenue_yoy`、`net_income_yoy`。单季毛利率用累计营收和营业成本还原。ROIC = 营业利润 × (1 − 所得税/利润总额) / (所有者权益 + 短期借款 + 长期借款)，税率需要落在 0 到 1。PE 用未复权价（有 `raw_close` 时不用复权收盘价）和公告日后的总股本，分子是最近四个单季归母净利润。M3 的总市值用同一套未复权价和总股本。名次相同按股票代码排序。这三套不套用默认的价格、市值、成交额和次新过滤。截断在筛选函数里按交易日完成，选股和回测看到的是同一批股票。

外部回测记录（2023-01 至 2026-10，已扣单边 0.15% 交易成本，不是这次在本仓库里重跑的结果）。不截断时：M1 累计 +68.7%，年化 14.9%，最大回撤 -27.6%；M2 累计 +34.9%，年化 8.3%；M3 累计 +41.3%，年化 9.6%。对照的全 A 等权年化是 11.0%。

截断之后的记录，同一区间、同样扣费：M1 综合名次前 20 年化 16.7%、回撤 -29.4%；前 30 年化 14.4%、回撤 -27.7%；前 50 年化 14.9%、回撤 -24.8%。M3 按总市值取前 30 年化 14.0%、回撤 -24.9%。M2 再做集中持仓更差，所以默认留下全部通过的股票。入选数量和排序方式是事后选定的，区间里大约 12 次再平衡，有过拟合风险。这组数字还有三处不能当成实盘预期：幸存者偏差、行业用的是当前同花顺分类而不是历史成分、WACC 固定为 8%。

## 扩展策略的三种方式

### 🎛️ 方式一:自定义信号(不写代码)

在选股页 UI 上用 `字段 + 操作符 + 阈值` 组合,编译成 Polars 表达式热加载。适合:

- 快速验证一个简单的筛选思路(如 `RSI < 30 AND 量比 > 2`)
- 不熟悉 Python 但想自定义筛选条件

底层实现在 `backend/app/strategy/custom_signals.py`。

### 🤖 方式二:AI 生成

一句话描述思路,LLM 读取精简运行时指南生成完整策略文件:

1. **配置 AI 接口**(留空即关闭,见 [configuration.md → AI](./configuration.md#ai可选)):
   ```ini
   AI_PROVIDER=openai_compat
   AI_BASE_URL=https://api.deepseek.com/v1
   AI_API_KEY=sk-...
   AI_MODEL=deepseek-chat
   ```
2. 在选股页打开「AI 策略生成器」,用自然语言描述你的策略思路
3. 前端流式接收生成代码,后端经 `ast` 安全校验(禁止 import os/sys/subprocess 等危险模块)后返回结果
4. 保存后落入 `data/strategies/ai/`,文件名/ID 用 `ai_` 前缀

生成策略相关提示词位于 `backend/app/strategy/prompts/`:

- `strategy-guide-compact.md` — AI 运行时精简指南(用于降低长请求超时概率)
- `strategy-guide.md` — 完整策略开发规范(供人工开发和详细参考)
- `strategy-builder-step2.md` — 步骤 2 提示词模板(修改已有策略)
- `strategy-example.md` — 从零创建强势反包策略的三步演示

> 💡 **文件与范围铁律**:AI 生成的策略只生成一个 `.py` 文件,只 `import polars as pl`,绝不修改 `backend/`、`docs/`、`frontend/` 等现有文件。

生成之后的持续改进(假设—验证—判定闭环),见 [AI 策略迭代指南](./strategy-iteration.md)。

### 📝 方式三:自定义编写 / 代码迁移

可以在选股页「自定义编写」中直接编辑策略代码并保存,新建自定义策略会落入 `data/strategies/custom/`,文件名/ID 用 `custom_` 前缀。也可以手动把已有策略改写为 Polars 文件后放入该目录,引擎会自动发现。

手写策略需遵循 [`strategy-guide.md`](../backend/app/strategy/prompts/strategy-guide.md) 的文件结构(META / basic_filter / scoring / ENTRY_SIGNALS / filter 等),完整规范见该文档。

## 策略文件结构(简述)

一个策略 `.py` 文件通常包含:

| 部分 | 作用 |
| :--- | :--- |
| `META` | 策略元信息(名称、参数、方向等),用户可在 UI 调整阈值 |
| `basic_filter(df, params)` | 模式 A:单日过滤,返回 `pl.Expr` |
| `filter_history(df, params)` | 模式 B:历史窗口过滤,返回 `pl.DataFrame`(配 `LOOKBACK_DAYS`) |
| `scoring` | 评分权重,总和 = 1.0 |
| `ENTRY_SIGNALS` / `EXIT_SIGNALS` | 进出场信号列(回测用) |

完整字段说明与示例见 [`strategy-guide.md`](../backend/app/strategy/prompts/strategy-guide.md)。
