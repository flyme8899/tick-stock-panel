# 选股字段对照（InStock 综合选股）

对照对象是 InStock `TABLE_CN_STOCK_SELECTION`（东财综合选股）。TSP 的条件字段来自指标列、内置信号和因子注册表。只接入本地已经有口径的字段。缺数据的列不编造。

状态：

- **已有**：这次改动之前就能当条件或信号用。
- **本次接入**：这次补进条件、信号，或策略结果列。标注「结果列」的字段还不能当自定义信号条件。
- **需新数据**：本地没有对应序列，或口径对不上。
- **本地已有但未接条件**：数在 parquet 里，但没有点时条件列。接进去要单独的公告日门控和测试，这次不做。

## 事件

限售解禁的下一次日期和占解禁前流通市值比例是结果列 `next_unlock_date`、`unlock_float_ratio`（未来 120 天内最近一次，**本次接入**，还不是条件列）。定向增发、资产重组、股权质押、商誉、机构评级和调研、股吧人气，本地都没有对应表。这些仍然是 **需新数据**。龙虎榜、融资融券、大宗交易在别的页面使用，没有接成选股条件列，记为 **本地已有但未接条件**。
